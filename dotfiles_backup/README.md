# Sauvegarde des Dotfiles (Hyprland, Waybar, Quickshell, etc.)

Sauvegarde effectuée le 4 octobre 2026 avant la remise à zéro des configurations.

## Contenu :
- `hypr-current/` : Configuration Hyprland précédente (Everything-dots / Lua).
- `everything-dots-backup/` : Sauvegardes antérieures de Hyprland (style ZaneyOS).
- `waybar-jakoolit/` : Configuration Waybar précédente complète avec tous ses modules (JaKooLit).
- `quickshell/` : Configuration de l'interface Nothing / Quickshell.
- `swaync/` : Configuration du centre de notifications SwayNC.
- `rofi/` : Configuration du lanceur d'applications Rofi.
- `wlogout/` : Menu de déconnexion / extinction Wlogout.

Une archive complète compressée `.tar.gz` est également disponible à la racine du dépôt.
