# Intent

**Quiet, precise hardware: black glass, white dot-matrix light, and one small
spark of colour. Nothing on screen that doesn't need to be there.**

Every change gets checked against that sentence. The decisions that follow from it:

| Decision | Choice |
|---|---|
| Colour | Neutral near-black (or near-white) surfaces. One accent, from a wallpaper colour you pick (Lead colour), or hand-picked. "On" is white, not accent. |
| Where colour goes | Only signals: today, weekends, rain chance, charging, recording, the dot. |
| Radius | One number (`look.radius`, default 20) for every surface: windows, pill panels, cards, tiles, launcher, widgets, lock screen. Controls are capsules. |
| Gap | One number (`look.gap`, default 8): window-to-window, window-to-edge, window-to-pill, pill margin. |
| Type | Instrument Serif for hero numbers and headings. Space Mono for everything else. Dot matrix for clocks and weather glyphs. Terminals keep a Nerd Font mono. |
| Icons | Material Symbols Rounded, weight 300, everywhere in the shell. |
| Focus | No borders: the focused window is solid and the rest are frosted glass. |
| Motion | One curve (OutQuint, ~480 ms). Things morph; they don't pop. |
| Cursor | Bibata Modern Classic, 24. |
| Screenshots | Clean desktop, widgets on, no stacked notifications. |
